# Calculator

A simple calculator built with HTML, CSS and JavaScript as part of my
CodeAlpha Frontend Development Internship.

## Features
- Addition, subtraction, multiplication and division
- Clear (AC) and delete (DEL) buttons
- Real-time display of the current number and operation
- Keyboard support
- Responsive design for phones and desktops

## Technologies
HTML, CSS, JavaScript

## How to use
Open `index.html` in your browser.
